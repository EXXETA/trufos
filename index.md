  - title: Offline, no account
    text: No registration, no login, no cloud sync and no telemetry. All data stays on your machine.
  - title: Made for Git
    text: Collections are plain JSON files on disk, so you can diff, review and share them like code.
  - title: Large payloads
    text: Big request and response bodies are handled without blocking the UI.
  - title: Environments and variables
    text: Switch between environments and reuse values across requests with variables.
  - title: Authentication
    text: Basic, Bearer/JWT, Digest, OAuth 1.0 and OAuth 2.0, inherited from folders and collections, plus mTLS.
  - title: Scripting
    text: Run pre-request and post-response scripts to prepare requests and process responses.
  - title: Import and export
    text: Bring in Postman, Bruno and OpenAPI collections, and export collections as ZIP archives.
  - title: Collection Runner
    text: Run all requests of a collection or folder in one go.
  - title: Plugins and MCP
    text: Extend Trufos with plugins, and let AI clients work with your collections through the built-in MCP server.
