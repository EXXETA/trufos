# User Guide

This section explains how to use Trufos. To get the app, see [Download]({% link download.md %}). To work on Trufos itself, see [Contributing]({% link documentation/index.md %}).

- [First Steps]({% link documentation/user-guide/first-steps.md %}): install Trufos, send your first request and find your data and logs.
- [Collections and Requests]({% link documentation/user-guide/collections.md %}): create and open collections, organise requests in folders, save and discard changes.
- [Variables]({% link documentation/user-guide/variables.md %}): reuse values across requests and switch between environments.
- [Authorization]({% link documentation/user-guide/authorization.md %}): Basic Auth, Bearer tokens, Digest, OAuth 1.0 and 2.0, inheritance and client certificates.
- [Import and Export]({% link documentation/user-guide/import-export.md %}): bring in collections from Postman, Bruno and OpenAPI, and export them as ZIP archives.

Questions and ideas are welcome on [Discord]({{ site.discord_url }}) and in the [issue tracker](https://github.com/EXXETA/trufos/issues).
