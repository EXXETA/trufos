# Contributing

Trufos is developed in the open on GitHub at [EXXETA/trufos](https://github.com/EXXETA/trufos). This section is for people who want to work on the app itself. If you want to use Trufos, see the [User Guide]({% link documentation/user-guide/index.md %}) instead.

1. Read the [Contribution Guidelines]({% link documentation/CONTRIBUTING.md %}) and the [Code of Conduct]({% link documentation/CODE_OF_CONDUCT.md %}).
2. Set up your environment with [Getting Started]({% link documentation/getting-started.md %}).
3. Find your way around the code with [Project Structure]({% link documentation/project-structure.md %}).

The [Architecture]({% link documentation/architecture/index.md %}), [Services]({% link documentation/services/index.md %}), [UI Components]({% link documentation/ui-components/index.md %}) and [Development]({% link documentation/development/index.md %}) sections go into more detail.

Questions are welcome in the [issue tracker](https://github.com/EXXETA/trufos/issues) and on [Discord]({{ site.discord_url }}).
